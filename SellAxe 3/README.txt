SellDonutSMP by Hai Tran - addon Meteor cho Minecraft 1.21.11 (Fabric)

Gom 3 module: SellAxe, AutoPay va AutoSell.

BUILD TREN GITHUB
1) Dua TOAN BO noi dung thu muc nay (khong phai ca thu muc cha) len repo GitHub,
   nho co thu muc an .github/workflows/build.yml. Hay keo tha file, dung copy-paste noi dung.
2) Vao tab Actions, chon "Build SellDonutSMP" (hoac day mot commit moi de no tu chay).
3) Chay xong (dau tick xanh) thi mo lan chay do, keo xuong muc Artifacts, tai "SellDonutSMP".
   Giai nen ra file SellDonutSMP-1.0.0.jar (dung file khong co -sources).
4) Bo vao thu muc mods cung Fabric Loader, Fabric API va Meteor Client cho 1.21.11.
   Xoa het cac file SellAxe / SellDonutSMP cu truoc khi bo ban moi.

BUILD TREN MAY (can JDK 21 va Gradle 9.2 tro len): gradle build
File jar nam trong build/libs/.
